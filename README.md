## Description
This repository contains my completed Python zyLab assignments (Modules 1-9) for CSCE 2120.

## Files Included
* `main1.py`: Implements fundamental vector operations from scratch without NumPy, including component-wise addition, scalar multiplication, magnitude calculation, and computing 2D direction angles.

* `main2.py`: Calculates vector dot and cross products, implements vector projection, and computes the distance from a 3D point to a plane using standard Python without external libraries.

* `main3.py`: Implements elementary row operations, identifies matrix echelon structures, and solves linear systems using a custom Gauss-Jordan elimination algorithm without external libraries.

* `main4.py`: Calculates matrix addition, scalar multiplication, and matrix-matrix multiplication, and verifies vector solutions to linear matrix equations without using NumPy.

* `main5.py`: Verifies inverse matrix identities, executes block matrix multiplication, computes exact 2x2 inverses, and finds the inverse of general 2x2 matrices using Gauss-Jordan elimination.

* `main6.py`: Constructs a 3-state weather Markov model using a weighted adjacency matrix and recovers previous weather distributions by implementing LU decomposition and Cholesky factorization solvers.

* `main7.py`: Computes linear combinations, determines vector span membership and linear independence, and extracts basis vectors to calculate subspace dimension using reduced row echelon form (RREF).

* `main8.py`: Implements vector coordinate extraction and change-of-basis conversions, and computes the basis vectors for the four fundamental matrix subspaces (column, row, null, and left null spaces).

* `main9.py`: Caculates matrix determinants using        recursive cofactor expansion, determines matrix invertibility, and uses determinants to compute the area and orientation of 2D triangles without relying on external libraries like NumPy.

## How to Run
Navigate to the root directory and execute any of the scripts using Python. For example:
`python3 main1.py`
